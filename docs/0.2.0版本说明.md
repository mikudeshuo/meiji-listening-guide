# 梅酱的听课指南 0.2.0

在 0.1.85 的基础上精简：移除与听课无关的功能，整理源码结构，修复几处界面问题。保留功能的行为不变，旧课程资料可直接使用。

## 相对 0.1.85 的变化

移除：通讯助手（QQ、微信）和研究工作流（研究 Agent、MCP、学习记录、我的笔记），以及它们使用的依赖和 NapCat 组件。知识库组件因此从约 142 MiB 减到约 23 MiB。资料目录里已有的 im-connections.sqlite3、research-native.sqlite 等文件不再读取，也不会被删除。

调整：运行组件的安装入口从「工具与工作流 → 运行环境」移到「设置 → 运行组件」。

修复：练习详解和视频课程笔记里的链接现在会在系统浏览器中打开；在侧栏选择其它课程或会话、在课次下拉里选择其它课次时，上一个留下的错误提示会消失。

课程数据库：结构变更改为按版本号执行，版本记在数据库的 user_version 中。0.2.0 打开旧课程库后版本号为 1，表结构和数据与 0.1.85 打开的结果相同；0.1.85 及更早的程序仍能打开升级后的课程库。由更高版本程序写过的课程库会被拒绝打开，且不做任何改动。

内部整理：源码统一排版并加入 ESLint；合并重复的辅助函数；后台操作改为处理表，界面调用在编译期检查操作名和返回类型；大界面组件拆成独立文件，主界面的状态按领域归入 hook。

## 已验证

类型检查、构建和完整目录打包通过。打包后的程序用隔离的空数据目录启动，18 个页面和课程界面的 17 个状态（选课程与课次、五个标签页、字幕搜索、保存字幕成功与失败、任务记录、切换课程、深色主题等）与从源码启动的结果一致，无控制台报错。

课程数据库升级：把数据库构造成 6 种历史结构，分别用 0.1.85 的代码和 0.2.0 的代码打开，升级后的表结构、全部数据行和完整性检查一致；用两份真实课程库的副本重复同样的对照，结果一致。登录档案使用的系统加密封装与 0.1.85 的实现互相可读。

## 尚未验证

真实账号下的模型对话、笔记与练习生成、智云、B 站登录、视频下载和离线转写没有实测；链接点击需要已有练习详解或视频笔记，未在应用内实测。安装包（NSIS）未构建，只验证了完整目录。THIRD_PARTY_NOTICES.md 未重新生成，仍列有已移除的依赖。
