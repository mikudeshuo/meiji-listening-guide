# 架构与模块边界

React 页面通过隔离 preload 桥访问主进程业务接口。主进程持有账号与模型连接，知识库和媒体下载在独立 TypeScript 工作进程内运行，通过有限消息协议协作；不启动 Python、yt-dlp 或 BiliSum 网页服务器。

知识库使用 knowledge-native.sqlite、中文全文与本地 BGE ONNX。旧 JSON/SQLite 只读建立基线。

媒体下载使用各平台原生目录、ETag/范围/哈希断点及原生并行传输，FFmpeg 只处理本任务下载到本地的文件，守护进程负责取消和退出。结果时长、画面、音轨、字幕和哈希通过后，才清理任务中间文件。

登录档案由 media-auth.ts 管理，DPAPI 密文不会导出为 Cookie 临时文件；下载元数据及媒体请求分别按目标域匹配。选用加密任务记录时由 media-jobs.ts 保存 job.dpapi，恢复与成果核验仍走同一队列。

ASR 使用独立 TypeScript 进程和本地 Whisper/Silero ONNX。PDF 增量批注、二维码、来源和导出均在原生应用逻辑内完成。FFmpeg、SQLite、ONNX、QuickJS WASM、Electron 与模型连接 CLI 是独立第三方组件。

主窗口禁用 nodeIntegration，开启 contextIsolation/sandbox，仅允许主框架调用已登记 IPC。每个业务接口通过明确类型依赖获取服务。业务接口按领域写成处理表（src/main/ipc/*.ts 中的 defineHandler），表的键就是操作名；src/main/ipc/contract.ts 从这些表推导出操作名与返回类型，界面的 invoke 据此在编译期检查操作名并得到返回类型。参数仍由各处理函数在运行时用 zod 校验。UI 不导入 Node 或展示上游网页。

课程、知识库和下载各自管理持久事务与取消；成果必须核验，模型未知结果不自动重试。关闭应用停止所属子进程，不强制结束用户的其它应用。历史实现保存在「历史参考」压缩归档，当前打包配置不读取该目录。
